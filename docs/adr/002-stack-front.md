# ADR-002 : stack front
**Statut** : accepté

**Décision** : React + Vite + TypeScript strict, PWA installable.
**Pourquoi** : plus large écosystème, meilleure fiabilité de Claude Code.
**Libs** : choisies au fil des besoins (routeur, TanStack Query, graphes, plugin PWA). Alternative écartée : SvelteKit.
