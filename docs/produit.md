# Produit

App 3 en 1 : suivi de musculation, suivi alimentaire, suivi de tâches gamifié. Remplace des apps dont les fonctions sont derrière des paywalls (graphes, macros) ou sans âme (tâches).

## Principes
1. Rien n'est verrouillé : toutes les stats et tous les graphes sont accessibles.
2. Données synchronisées téléphone / PC via le cloud, avec export JSON.
3. Connexion requise (cloud-first).
4. Coût : 0 €.
5. Saisie rapide.

Un seul compte. Hors périmètre : multi-utilisateurs, social, stores.

## Gamification
Chaque module garde ses stats et streaks, rien n'est mélangé.
- Muscu : sobre (records, calendrier, graphes). Pas d'XP.
- Nutrition : sobre (anneaux, streak de jours suivis). Pas d'XP. On récompense la régularité, pas « manger moins ».
- Tâches : XP, niveaux, quêtes, boss, badges, récompenses.

## Muscu
- Bibliothèque par groupe (10 groupes : Pecs, Dos, Épaules, Biceps, Triceps, Quadriceps, Ischios, Fessiers, Mollets, Abdos), exercices avec image, exercices perso, fiche exercice (records, 1RM estimé, courbe, historique, consignes).
- Programmes (séances types, jours/semaine), séances (exercices, séries, reps, repos).
- Séance en cours : feuille par-dessus l'app, réductible en barre. Saisie poids / reps / RPE, dernière perf, minuteur de repos, chrono, volume.
- Accueil : résumé de la semaine, dernières séances.
- Profil : 3 graphes (3 mois), récupération par muscle, muscles sollicités (silhouette face/dos), calendrier ; onglet Exercices ; onglet Stats avancées.
- Pas de suggestion de progression automatique.

## Nutrition
- Journal du jour (4 créneaux), anneaux (kcal + macros), fibres, sucres, sel, navigation par jour.
- Aliments avec toutes les macros ; recherche Open Food Facts, scan code-barres, aliments perso, favoris, récents.
- Repas enregistrés, « Enregistrer comme repas », « Copier hier ». Pas de recettes détaillées ni de micronutriments.
- Eau : carte, écran détail, objectif.
- Stats 7 j / 30 j / 3 mois, objectifs.

## Tâches
- Tâches (titre, catégorie, priorité, difficulté, échéance, récurrence, sous-tâches, notes), vue Aujourd'hui, À venir.
- Habitudes (jours, moment, fait/compteur, rappel, difficulté, pause, archivage), routine du jour par moment.
- XP, niveaux, écran de récompense, quêtes du jour/semaine **créées par Hugo**, boss de la semaine, badges, récompense perso par niveau, anti-triche.

## Transverse
Accueil global, bouton maison dans chaque module, onglets par module, export/import JSON, compte, synchro.
